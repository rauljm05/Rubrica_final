# Iris Species Classification – Data Mining Project

Este proyecto fue desarrollado como trabajo final del curso de **Minería de Datos** de la **Universidad de la Costa**. El objetivo es clasificar especies de flores del dataset Iris utilizando técnicas de aprendizaje automático y representar los resultados mediante un dashboard interactivo.

## Objetivo del Proyecto

Entrenar un modelo de clasificación capaz de predecir la especie de una flor según las dimensiones del sépalo y del pétalo. Para ello, implementé un flujo completo de minería de datos, desde la comprensión de los datos hasta la visualización de resultados.

---

## Metodología Aplicada (Workflow)

1. **Data Understanding:** Cargué y analicé el dataset Iris, revisando características, balance de clases y distribución de datos.  
2. **Preprocesamiento:** Realicé escalamiento y división del dataset en entrenamiento y prueba.  
3. **Modelado:** Entrené un modelo *Random Forest* por su robustez y precisión en problemas de clasificación.  
4. **Evaluación:** Validé el rendimiento utilizando métricas como *Accuracy, Precision, Recall* y *F1-Score*.  
5. **Dashboard (Streamlit):** Creé una interfaz interactiva para mostrar métricas, visualizaciones y predicción.  
6. **Conclusiones:** Interpreté los resultados y destaqué posibles mejoras para futuros trabajos.
